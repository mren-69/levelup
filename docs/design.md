# 自分専用「リアル・レベルアップ」アプリ 設計書

作成日: 2026-11-04 / 状態: **承認待ち(ユーザーが「作り始めてください」と言うまで実装しない)**

## 1. 目的
『俺だけレベルアップな件』のように、日常の行動(筋トレ・勉強・就寝・禁欲・スマホ時間)をクエストにして、達成するとアバターのレベルが上がるアプリを、ユーザー1人のために作る。続ける理由を毎日目にすることが狙い。

## 2. ゴール / ノンゴール / アンチゴール
- ゴール: 毎日開いて、数タップで記録できる。レベルが上がる実感がある。Lv2まで約2日、Lv50まで約半年。
- ノンゴール: App Store公開、他人への配布、ランク(ゴールド等)、シーズン、SNS機能、不正対策(自己申告で良い)、役職によるアバターの見た目変化。
- アンチゴール: 基準が甘くなる設計(自由入力の経験値など)。サボった数日分が積み上がって挫折する設計(倍率の暴走)。

## 3. 作り方(ここは私の判断)
- iPhoneのホーム画面に追加して使うWebアプリ(PWA)。オフライン(Wi-Fiなし)で動く。
- データは端末内に保存。消えたときのため、書き出し・読み込み(バックアップ)機能を付ける。
- iPhoneのホーム画面に追加するには、HTTPSで公開された場所が必要。無料の公開先を使う(下の「未決定」参照)。
- 通知はアプリからは出さない。iPhoneの「ショートカット」のオートメーションで毎日決まった時刻に通知する。設定手順は設定画面にも載せる。

## 4. デザイン
`mockups/mockup-b2.html`(案B2「黒×青×金のシステム」)をそのまま使う。青=システム、金=経験値・レベル・役職・報酬。ホーム、クエスト一覧、使用時間の記入の3画面が見本。
ホームには、レベルの大きな数字、役職、区切りのある経験値バー、「あとXPでレベルUP」、アバター画像を出す。名前の表示はなし。

## 5. クエスト
- ユーザーが自分で作る。名前、繰り返し(毎日/曜日指定。ここは私の判断)、**経験値の枠**を選ぶ。
- 経験値の枠は固定で、自由入力はできない: **5 / 10 / 15 / 20 / 30 / 45 / 60 / 80 / 100**。
- 種類は2つ。
  - **量のあるクエスト**(腕立て◯回、勉強◯時間など): 基準の量を持つ。
  - **量のないクエスト**(就寝、自炊、自慰控え、スマホ使用時間の「〜以内」など)。
- 達成はユーザーがチェックを入れる自己申告。
- クエストごとにいつでもオン/オフできる(旅行、体調不良用)。オフの間は達成扱いも未達成扱いもされない。

## 6. レベルと役職
- 1つ上がるのに必要な経験値: Lv1→2は170、上がるたびに+8(Lv n→n+1 = 170 + 8×(n−1))。1日100XPなら、Lv2まで約2日、Lv50まで約177日。
- Lv50より先も同じ式で上がり続ける(私の判断)。レベルは下がらない。
- 役職(レベルが上がると自動で変わる。変わる瞬間は画面で祝う)。

| レベル | 役職 |
|---|---|
| 1〜2 | 戦士 |
| 3〜5 | スパルティアタイ |
| 6〜10 | 麒麟児 |
| 11〜16 | 闘将 |
| 17〜20 | 万能の天才 |
| 21〜30 | 怪物 |
| 31〜36 | 英雄 |
| 37〜40 | 皇帝 |
| 41〜55 | 一族の最高傑作 |
| 56以上 | 人類の最高到達点 |

## 7. ペナルティ
- 対象は量のあるクエストだけ。逃した翌日の量が×1.25になる。続けて逃したら次の日は×1.5。上限は×1.5。
- 端数は四捨五入。ただし最低でも+1(腕立て5回→6回→8回)。
- 経験値は減らさない。
- 翌日に増えた量をこなせば、その次の日から元の量に戻る。リカバリークエストをやったかどうかは関係しない。
- 増えた量もこなせなかった日は、次の日が×1.5になる(上限)。
- 量のないクエスト(スマホ使用時間の「〜以内」を含む)にはペナルティなし。経験値がもらえないことがペナルティ。

## 8. リカバリークエスト
- 量のあるクエストを逃した翌日に、アプリが1つ提示する。量のないクエストでは出さない。
- 内容は逃したクエストと無関係で良い(朝の散歩、コールドシャワーなど)。軽めのもの。
- 「承認」「拒否」の2つの文字を並べて選ぶ。拒否しても、ペナルティの扱いは変わらない。
- 経験値: 逃したクエストの経験値が20未満なら2割、20以上なら1割(端数は四捨五入、最低1)。
- 候補は**30個以上**を用意し、完全ランダムで出す。**候補の中身はユーザーに見せない**(ユーザーの楽しみ。設計書にも書かない)。画面に出るまで、ユーザーは候補一覧を見ない。毎回、全候補の中から完全ランダムで1つ選ぶ。同じものが連続して出てもよい(ユーザー指定)。

## 9. お休みシールド
- 週に1回、クエスト1個分の未達成を帳消しにできる。逃した**翌朝以降に後から**使う。
- 月曜日になった瞬間(月曜3:00。第12章参照)に補充される。
- 週の終わりまで使わなかったら、ボーナス経験値が入る。量は**20XP(私の判断)**。
- 旅行などのお休みは、シールドではなく、クエストごとのオン/オフで扱う。
- シールドで帳消しにしたクエストは、ペナルティの対象にならない。

## 10. スマホ使用時間
- 自動では取れない。1日1回、スクリーンタイムの数字(時間・分)を入力する(昨日分)。
- 「◯時間以内」のクエストとして登録する。入力した数字が基準以内なら、自動で達成扱いになる(私の判断)。経験値の枠は他のクエストと同じ中から選ぶ。
- 量のないクエスト扱い(ペナルティなし)。

## 11. アバターと写真
- 「アバター」と「写真」の2つを、それぞれ1回だけ設定する。その後は画面上で「アバター」「写真」をタップするだけで切り替わる。
- 写真は、iPhoneの写真ライブラリやファイルの中から自由に選べる。
- アバターは最初は仮のシルエット。画像を入れれば差し替わる。
- 五角形のパラメータは最初の版には入れない。あとから足せるように作る。

## 12. 日付の扱い(私の判断)
- 1日の区切りは**朝3:00**(ユーザー指定)。0:00〜2:59は「前の日」として扱う。
- 週の区切りとシールドの補充も、月曜日の3:00に合わせる(私の判断。ユーザーの「月曜日になった瞬間」を、1日の区切りに揃えた)。

## 13. 未決定・あとで決めること
- 五角形パラメータの5つの項目。
- 公開先(無料のHTTPSホスティング。GitHub PagesかCloudflare Pagesを提案予定)。アドレスを知っている人しか開けない形で問題ないと、ユーザーが了承済み。データは端末内にあるので、他人には見えない。

## 15. 緊急クエスト(2026-11-04 追加)
- その日かぎりの1回きりのミッション(親に頼まれたお使いなど)。クエスト画面から、名前と経験値(普通のクエストと同じ枠5〜100)を入れて追加する。1日にいくつでも追加できる。
- 「できた/できない」のチェックだけ(量なし)。チェックで経験値が入り、外すと戻る。終わる前なら削除できる。
- 追加した日の朝3時になると、できていなくても消える。ペナルティ・リカバリークエスト・シールドは関係しない。できた分の経験値は消えたあとも残る。
- 見た目は赤く光る「EMERGENCY」。クエスト画面の一番上と、ホームのカードに出す。

## 16. クエストの並べ替え(2026-11-04 追加)
- 「すべてのクエスト」と「今日のクエスト」の両方で、行を長押し(約0.45秒)してドラッグすると並べ替えられる。長押しが短いとスクロールと混ざるため、少し長めにしてある(私の判断。ユーザー了承済み)。
- すべてのクエストの順番は保存され、翌日以降も同じ。新しいクエストは一番下に入る。
- 今日のクエストの順番は、最初はすべてのクエストの順番に従う。今日のクエストで並べ替えても、すべてのクエストには反映されず、**今日だけ**有効。翌日はすべてのクエストの順番に戻る。
- すべてのクエストを並べ替えたら、今日のクエストもその順番に合わせ直す(今日だけの並べ替えは上書き)。
- 緊急クエストは並べ替えの対象外で、いつも一番上に出る。

## 17. 緊急クエストの「明日の予約」(2026-11-09 追加)
- 緊急クエストの追加画面で、「今日」か「明日(予約)」を選べる。予約できるのは明日だけ(ユーザー指定)。
- 予約したものは、クエスト画面の「明日の予約」の欄に出る(今日のクエストには出ない。経験値も入らない)。明日になる前なら削除できる。
- 明日の朝3時を過ぎると、普通の緊急クエストになる(赤く光るEMERGENCY、一番上)。その日の朝3時に消えるのも同じ。予約したまま2日以上開かなかったときは、発動する日が終わっているので消える。
- 予約の欄の見た目は、まだ発動していないことが分かるように、緊急クエストより落ち着いた赤の破線の枠(私の判断。ユーザー了承済み)。
